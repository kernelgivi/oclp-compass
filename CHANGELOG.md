# Changelog

## 0.2.0 — 2026-11-08

- Replaced the original dashboard with a six-workspace interface using larger type, graphite/amber surfaces, an inspectable system drawing, and restrained technical styling.
- Added dark/light modes, standard/large text sizes, a searchable command palette, contextual score explanations, table filtering/sorting, and mobile layouts.
- Added pairwise version comparisons with signed preference deltas in the GUI and CLI.
- Added target-specific plans with downgrade/same-major cautions, per-target human confirmations, and Markdown export. Excluded targets receive preparation guidance only.
- Added non-mutating RAM/drive simulations, searchable reviewed models, profile import/export, and authenticated hardware rescanning.
- Added outcome/OS/text report filters and accurate bundled-versus-imported corpus metadata.
- Added readable Markdown analysis reports and `compare`, `plan`, and `simulate` terminal commands.
- Rejected duplicate JSON keys, non-finite JSON constants, unsafe source-link characters, and noncanonical evidence dates.
- Added input/plan/report/scenario tests and exercised the real Chromium workflow. Corrected narrow-screen overflow caused by a visually hidden label escaping its table's scroll container.
- Standardized Python and web-source formatting; added a Node lockfile. Runtime dependencies remain empty.

The model catalog and two-report seed corpus are unchanged. No new benchmark, broad community consensus, or physical Intel-Mac validation is claimed.

## 0.1.0 — 2026-11-08

- Initial local GUI and CLI, 52 reviewed model profiles, explicit ranking assumptions, app constraints, two source-linked reports, and a capability-authenticated loopback server.
